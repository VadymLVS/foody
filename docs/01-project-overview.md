# PantrySync — Обзор проекта

## Суть

Приложение, которое отвечает на два бытовых вопроса:

1. **«Что купить?»** — открываешь перед магазином, видишь чего не хватает. Один тап на тоггл — отметил.
2. **«Что приготовить?»** — приложение знает, что лежит дома, и предлагает блюда, которые можно сделать прямо сейчас.

Второй вопрос — главная причина существования продукта. Первый — фундамент, без которого второй невозможен.

Всё синхронизируется между членами семьи в реальном времени. Приглашение — по ссылке, без email-рассылок и аккаунтов «для галочки».

## Целевая аудитория

Люди 25–45, которые готовят дома и ходят в магазин. Отдельно — те, кому тяжело каждый день решать, что есть: для них выбор блюда должен быть не задачей, а развлечением на 20 секунд.

## Ключевые принципы UX

- **Мгновенный отклик.** Тоггл переключается локально, до ответа сервера. Ошибка сети — откат с уведомлением.
- **Минимум касаний.** Основное действие — одно касание. Подтверждения только для необратимого.
- **Ничего не теряется.** Удаление обратимо 5 секунд. Количество не сбрасывается само.
- **Совместность по умолчанию.** Изменения видны всем участникам кухни онлайн.
- **Mobile-first.** Интерфейс проектируется под 375px, десктоп — вторичен.
- **Светлая минималистичная тема.** Белые карточки, серый фон, один акцент (#34C759).

## Этапы

### MVP-1 — «Список» (текущий фокус)
CRUD продуктов, категории, количество, реалтайм, кухни и участники, share-ссылки, голосовой поиск, блюда с ингредиентами и признаком «можно приготовить», планирование покупок по блюдам.

### MVP-2 — «Выбор»
Утренний свайп-режим выбора блюд, план дня, характер приложения (реакции на спам-свайпы влево), «я приготовил это» со списанием продуктов.

### V2 — «Автоматизация»
Сканирование чека камерой с распознаванием купленного. **Это же — точка входа в App Store** (см. `05-store-readiness.md`).

### Не делаем никогда (или очень нескоро)
Сканер штрихкодов, история покупок, аналитика потребления, рецепты с пошаговым приготовлением, калории, интеграции с доставками.
