# PantrySync — Дизайн-система и структура Figma

> Версия 0.2. Изменения относительно 0.1 отмечены **▲**.

---

## 1. Правила работы в Figma

| Плохо | Хорошо |
|-------|--------|
| Group 47 | `ProductCard/Default` |
| Rectangle 12 | `Toggle/Background/Off` |
| Text | `ProductName/Body-Semibold` |
| 🔵 | `Color/Accent/Primary` |

- Auto Layout везде. Constraints прописаны (Hug / Fill).
- Компоненты через Variants, не через копипаст.
- Все цвета и размеры — через Variables (переменные), чтобы имена совпадали с токенами Tailwind.
- **Никаких эмодзи в макетах** **▲ D-012**. Иконки — библиотека Lucide, подключается как Figma-плагин.

## 2. Токены

### 2.1 Цвета

| Токен | Значение | Использование |
|-------|----------|---------------|
| `bg` | `#F5F5F7` | Фон экрана |
| `surface` | `#FFFFFF` | Карточки, модалы |
| `text-primary` | `#1C1C1E` | Основной текст |
| `text-muted` | `#8E8E93` | Вторичный текст, количество |
| `accent` | `#34C759` | Тоггл On, активные pills, FAB |
| `accent-light` | `#E8F5E9` | Фон панели количества |
| `accent-pressed` | `#28A745` | Нажатое состояние **▲ новое** |
| `danger` | `#FF3B30` | Удаление, ошибки |
| `warning` | `#FF9F0A` | Переподключение **▲ новое** |
| `border` | `#E5E5EA` | Разделители, обводки |
| `toggle-off` | `#E5E5EA` | Фон тоггла Off |
| `overlay` | `rgba(0,0,0,0.4)` | Подложка модалов **▲ новое** |

**Тёмная тема:** не в MVP-1, но все цвета заводятся как переменные с режимами Light/Dark, чтобы потом не переделывать. **▲ новое**

### 2.2 Типографика

| Стиль | Размер / Высота | Вес | Использование |
|-------|-----------------|-----|---------------|
| `Title` | 24 / 30 | Bold | Названия экранов |
| `Headline` | 18 / 24 | Semibold | Названия блюд |
| `Body` | 16 / 22 | Regular | Названия продуктов |
| `Body-Semibold` | 16 / 22 | Semibold | Активные элементы |
| `Caption` | 14 / 20 | Regular | Email, описания, количество |
| `Small` | 12 / 16 | Medium | Категории, метки |

Шрифт: системный стек (`-apple-system, SF Pro, Roboto`). Отдельный шрифт не подключаем — экономия загрузки и родной вид на обеих платформах.

### 2.3 Размеры

- Базовая сетка: **4px**
- Отступы: 4, 8, 12, 16, 20, 24, 32, 40, 48
- Скругления: `sm` 8 (кнопки, inputs), `md` 12 (карточки), `lg` 16 (модалы), `full` (pills, аватары)
- Тени: карточка `0 1px 3px rgba(0,0,0,0.06)`, модал `0 8px 32px rgba(0,0,0,0.16)`, FAB `0 4px 12px rgba(52,199,89,0.32)`
- **Минимальный тач-таргет: 44×44px** **▲ D-014**. Визуальный размер иконки может быть меньше — кликабельная зона нет.
- **Safe area:** нижняя панель и FAB учитывают `env(safe-area-inset-bottom)` **▲ D-014**

## 3. Компоненты

### 3.1 Button
Варианты: `primary` / `secondary` / `danger` / `ghost` / `icon`
Размеры: `sm` 36px, `md` 44px, `lg` 52px
Состояния: default, pressed, disabled, loading (спиннер вместо текста) **▲ loading новое**

### 3.2 Input
Варианты: default / focus / error / с иконкой слева / с иконкой справа
Высота 48px, скругление 8px, обводка 1px

### 3.3 Toggle
51×31px (стандарт iOS). Off: серый круг слева на `toggle-off`. On: белый круг справа на `accent`.
Анимация 200ms `ease-out`.

### 3.4 ProductCard
Варианты:
- `Default` — название, тоггл Off, иконка меню
- `InStock` — название, количество (если > 0), тоггл On
- `InStock-NoQuantity` — без количества **▲ уточнено: количество скрыто, не равно нулю (D-006)**
- `Active` — раскрытая панель количества под карточкой
- `Deleting` — состояние во время анимации удаления **▲ новое (D-009)**

Высота 64px, padding 16px, gap 12px.

### 3.5 QuantityPanel
Фон `accent-light`, высота 56px, скругление снизу 12px.
Слева «Количество, [единица]», справа `[−] [число] [+]`.

### 3.6 DishCard
Варианты: `Ready` (зелёная точка + «Готово») / `Missing` (серое «Не хватает N») / `Selectable` (чекбокс) / `NoImage` (плейсхолдер с буквой) **▲ NoImage новое**

### 3.7 CategoryPill
Active: заливка `accent`, белый текст. Inactive: обводка `border`, `text-primary`.
Высота 32px, padding 12px по бокам.

### 3.8 SectionHeader **▲ новое (D-007)**
Sticky-заголовок категории в списке продуктов. Высота 32px, фон `bg` с блюром, текст `Small` uppercase `text-muted`.

### 3.9 Toast **▲ новое (D-009)**
Тёмная плашка снизу над навигацией, скругление 12px, высота 48px.
Текст слева + кнопка-действие справа (`accent` текстом). Автоскрытие 5 сек с полосой прогресса.

### 3.10 Modal / BottomSheet / ContextMenu / EmptyState / FAB
Без изменений относительно v0.1. BottomSheet: handle 36×4px, скругление 16px сверху.

### 3.11 ConnectionDot **▲ новое**
8px. Зелёная (online) / жёлтая пульсирующая (reconnecting) / серая (offline).

## 5. Адаптив

| Брейкпоинт | Ширина | Особенности |
|-----------|--------|-------------|
| Mobile | 375 (основной макет) | Bottom Tab Bar, 2 колонки блюд, модалы снизу |
| Mobile L | 430 | То же, больше воздуха |
| Tablet | 768 | 3 колонки блюд, модалы по центру |
| Desktop | 1440 | Контейнер max-width 640px (список) / 960px (блюда), Tab Bar остаётся |

Десктоп — вторичен. Не тратим на него время в MVP-1 сверх того, чтобы не разваливалось.

## 6. Экспорт для разработки

- Все токены выгружаются в `tailwind.config.ts` — имена переменных Figma **должны совпадать** с ключами конфига.
- Иконки не экспортируются картинками: берутся из `lucide-react` по имени.
- Скриншоты для сторов генерируются из отдельного фрейма `Store/Screenshots` в требуемых размерах.
